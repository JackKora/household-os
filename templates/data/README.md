# Household OS Data

This private repository holds household context for the three Household OS skills. Open Codex or Claude Code from this directory so the project-scoped skills and local data are available together.

The default is not to save. Review any proposed baseline or material update before it is written. Workout history belongs only in the configured Notion database.

Generated skill links under `.agents/skills/` and `.claude/skills/` are local installation artifacts and are not committed.
