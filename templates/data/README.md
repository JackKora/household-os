# Household OS Data

This private repository holds household context for the five Household OS skills. Open Codex or Claude Code from this directory so the project-scoped skills and local data are available together.

The default is not to save. This repository keeps its fixed reviewed-baseline files and module-owned Markdown notes: `modules/financial-advisor/notes/`, `modules/general-contractor/notes/`, `modules/legal-advisor/notes/`, `modules/parenting/notes/`, and `modules/wellness-coach/notes/`. Use top-level `notes/` only for genuinely cross-functional content with no clear primary module. Ask conversationally to create, add, show, list, search, rename, or move a note. Notes are created only when first used, are not loaded automatically, and remain until you manually delete the Markdown file; deleted files may remain in private Git history. User-provided content may be written directly, but review assistant-generated or materially summarized note content before it is written. Keep sensitive legal strategy, attorney communications, evidence, and generated legal analysis out of this shared Git repository. Workout history and results belong only in the configured Notion database.

Generated skill links under `.agents/skills/` and `.claude/skills/` are local installation artifacts and are not committed.
